description: Check the repository for changes and update the documentation in the docs directory.
---

When triggered, please perform the following steps to ensure the project documentation is up to date:

1. Run `git status`, `git diff`, and `git log -n 5` to identify recent changes and understand what has been added, modified, or removed in the codebase.
2. Review the contents of the `docs/` directory to see the current state of the documentation.
3. Analyze the changed code files and determine what sections of the documentation (e.g., API references, architecture, setup instructions) are now outdated.
4. Use the appropriate tools to directly edit, add, or delete markdown files in the `docs/` directory to accurately reflect the latest changes.
5. Once complete, provide a summary to the user outlining exactly which documentation files were updated and what information was added or changed.
